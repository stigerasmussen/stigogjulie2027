# Stig & Julie – Kærlighedsfest 15. maj 2027

One pager med program, praktisk info, FAQ og location.

- `index.html` – den færdige side (alt er bygget ind i én fil). Kan lægges direkte på GitHub Pages, Netlify m.m.
- `src/` – kildefilerne: `page.src.html` (layout og tekst), `disco.js` (3D-diskoelementerne) og `build.py`, der samler det hele til én fil.
- `assets/` – billederne.

Indstillinger for ikon-stil og farver står øverst i `index.html` (`ICON_STYLE`, `PALETTE`).
